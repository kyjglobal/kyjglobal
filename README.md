# 김용준 · kyjglobal

Flutter 앱과 API·AI 서비스 연동을 중심으로 프로젝트를 개발합니다.  
운동 기록에서 AI 리포트까지, 사용자 화면과 데이터가 이어지는 흐름에 관심이 있습니다.

## 주요 프로젝트

### [mAIpt](https://github.com/seen02/mAIpt)
**AI 자세 코칭과 운동 기록을 결합한 모바일 서비스 · 팀 프로젝트**

- **담당:** Flutter 프론트엔드 및 AI 서버 연동
- FastAPI·Gemini 기반 운동 분석 API 초기 구현과 앱의 리포트 데이터 연동
- 운동 화면의 카메라·기록 저장 흐름, 인증 토큰 갱신과 세션 유지 처리 개선

[프로젝트 소개·기술 문서](https://github.com/seen02/mAIpt) · [Google Play](https://play.google.com/store/apps/details?id=com.maipt)

### [Gacha Log Analytics System](https://github.com/kyjglobal/gacha-log-analytics-system)
**가챠 시뮬레이션과 로그·확률 분석을 다루는 공개 프로젝트**

Flutter 클라이언트와 FastAPI 서버로 구성되어 있습니다. API, 데이터 구조와 로컬 실행 방법을 저장소에서 확인할 수 있습니다.

### ReproLoop
**Discord 기반 플레이테스트 버그 제보·피드백 관리 서비스 · 코드 비공개**

Discord 제보 접수, 관리자 웹의 제보 조회·상태 관리, 수정 완료 알림을 연결합니다. Web·Worker·공통 패키지로 나누어 제품 흐름과 협업 구조를 구성했습니다.
